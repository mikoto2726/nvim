このリポジトリは、Neovimの設定ファイルを管理しています。以下に設定の概要、使用しているプラグイン、インストール手順、カスタマイズ方法、トラブルシューティングについて詳しく説明します。

## プロジェクトの概要

この設定は、開発者がNeovimを効率的に使用するために設計されています。特に、JavaScript/TypeScriptやPythonを使用する開発者に最適化されています。

## インストール手順

1. **Neovimのインストール**: 最新バージョンのNeovimをインストールしてください。
2. **Packerのインストール**: プラグインマネージャーであるPackerをインストールします。
   ```bash
   git clone --depth 1 https://github.com/wbthomason/packer.nvim\
   ~/.local/share/nvim/site/pack/packer/start/packer.nvim

## 基本設定

- **カラースキーム**: `tokyonight`を使用し、背景を透明に設定しています。
- **行番号**: 行番号を表示します。
- **タブとインデント**: タブ幅とシフト幅を4に設定し、タブをスペースに変換します。
- **クリップボード**: システムクリップボードと連携します。

## プラグイン

### プラグインマネージャー
- **packer.nvim**: プラグインの管理に使用しています。

### ファイルツリーとアイコン
- **NERDTree**: ファイルツリーを表示します。
- **nvim-web-devicons**: ファイルアイコンを表示します。

### ステータスライン
- **lightline.vim**: 軽量なステータスラインを提供します。

### シンタックスハイライトと補完
- **nvim-treesitter**: 高度なシンタックスハイライトを提供します。
- **coc.nvim**: 補完機能とLSPサポートを提供します。

### コードフォーマットとリント
- **eslint.nvim**: JavaScript/TypeScriptのリントを行います。
- **prettier.nvim**: コードフォーマットを行います。

### その他
- **vim-gitgutter**: Gitの変更を表示します。
- **vim-rainbow**: 括弧の色分けを行います。
- **auto-pairs**: 自動で括弧を閉じます。
- **markdown-preview.nvim**: Markdownのプレビューを行います。

## キーマッピング

- **<C-n>**: NERDTreeをトグルします。
- **<Leader>/**: 検索ハイライトを解除します。
- **<Leader>th**: 水平分割でターミナルを開きます。
- **<Leader>tv**: 垂直分割でターミナルを開きます。

## カスタム設定

- **背景の透明化**: 背景を透明にする設定を行っています。
- **スペルチェック**: Pythonファイルでスペルチェックを有効化しています。

この設定は、Neovimをより効率的に使用するためのものです。各プラグインの詳細な設定やカスタマイズについては、`init.lua`を参照してください。
